# Credit-Card-Fraud-Detection
FraudWebApp is a machine learning powered web application for detecting fraudulent transactions. It integrates trained models, preprocessing tools, and a simple Flask interface with HTML/CSS templates. Includes datasets, reports, and Jupyter notebooks for analysis and evaluation.

🚀 Features
- Real‑time fraud detection using trained ML models
- Flask web interface with HTML/CSS templates
- Preprocessing pipeline for transaction data
- Jupyter notebooks for analysis and evaluation
- Reports and metrics (precision, recall, F1‑score)
